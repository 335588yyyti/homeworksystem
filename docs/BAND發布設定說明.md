# 把聯絡簿發到 BAND：設定步驟

看板上按「📣 發到BAND」→ 確認內容 → 輸入發布密碼 → 按「確認，發到BAND」，就會在班級 BAND 發一篇今日聯絡簿。

這個功能需要先做一次設定。整個流程大約 20～30 分鐘，**只需要做一次**。

## 為什麼要多一個「發布程式」？

發文到 BAND 需要一組「BAND 金鑰」（access token）。有了這組金鑰，就能用你的名義在 BAND 發文。

- 看板的程式碼是公開的，班級資料也是任何知道班級代碼的人都讀得到，所以**金鑰絕對不能放在看板裡**。
- 所以我們把金鑰放在你自己的 Google 帳號裡的一支小程式（Google Apps Script）。看板只把「聯絡簿內容＋發布密碼」交給它，由它去發文。
- 看板上只會存這支小程式的網址。沒有發布密碼的人，就算知道網址也發不出去；密碼連續打錯 10 次，會先擋 10 分鐘。

## 步驟一：拿到 BAND 的金鑰（access token）

1. 用電腦打開 BAND 開發者網站：<https://developers.band.us/>，用你平常登入 BAND 的帳號登入。
2. 到「我的服務／Register Service」建立一個服務，名稱隨意，例如「下課檢查站」。
3. 建好以後，在服務頁面找「Access Token」，按連結／產生，同意授權。
4. 把那一長串 access token 複製起來，**不要傳給別人、不要貼在群組裡**。

> 這幾個按鈕的名稱以 BAND 開發者網站上看到的為準；網站改版時位置可能不同。
> 本專案依照 BAND Open API 2.2 版的「發文」功能（`POST https://openapi.band.us/v2.2/band/post/create`，參數 `access_token`、`band_key`、`content`、`do_push`）撰寫；設定時請順便對照官方文件「Write a post」確認沒有變動。

## 步驟二：建立 Google Apps Script

1. 打開 <https://script.google.com/>，按左上角「新專案」。
2. 把專案名稱改成「下課檢查站 BAND 發布」。
3. 把編輯區裡原本的內容全部刪掉，貼上本專案的 `apps-script/band-publish.gs` 全部內容，按 💾 儲存。

## 步驟三：把金鑰和密碼放進「指令碼屬性」

1. 左邊點 ⚙️「專案設定」，往下找到「指令碼屬性」，按「新增指令碼屬性」。
2. 加這三個（左邊是名稱，要一字不差；右邊填你的值）：

| 屬性名稱 | 要填什麼 |
| --- | --- |
| `BAND_ACCESS_TOKEN` | 步驟一複製的 access token |
| `PUBLISH_PASSWORD` | 自己訂一組發布密碼，例如 8 碼以上的英文加數字，**不要跟看板的教師密碼一樣** |
| `BAND_KEY` | 先空著，步驟四查到再填 |

3. 按「儲存指令碼屬性」。
4. 如果不想讓家長手機跳出通知，可以再加一個 `DO_PUSH`，值填 `false`。

## 步驟四：查班級 BAND 的 band_key

1. 回到左邊「編輯器」（< > 圖示）。
2. 上方的函式選單選 `listMyBands`，按「▶ 執行」。
3. 第一次執行會跳出「需要授權」：按「審查權限」→ 選你的 Google 帳號 → 如果看到「Google 尚未驗證這個應用程式」，按「進階」→「前往（不安全）」→「允許」。這支程式是你自己的，只會連到 BAND。
4. 下方「執行記錄」會列出你所有的 BAND，每行是「BAND 名稱　→　band_key：一串英數字」。
5. 把班級 BAND 那一行的 band_key 複製，回到「專案設定 → 指令碼屬性」，填進 `BAND_KEY`，儲存。

## 步驟五：部署成網址

1. 右上角按「部署」→「新增部署作業」。
2. 左邊齒輪「選取類型」選「網頁應用程式」。
3. 設定：
   - 說明：隨意，例如「第一版」
   - 執行身分：**我**
   - 誰可以存取：**所有人**（看板要能連到它；沒有發布密碼還是發不出去）
4. 按「部署」，複製出現的「網頁應用程式網址」。網址長這樣：`https://script.google.com/macros/s/一長串/exec`

## 步驟六：在看板上貼網址、測試

1. 打開看板，進「教師登記」，到「早自習」頁。
2. 聯絡簿右上角按「📣 發到BAND」。
3. 打開「⚙️ 發布程式網址」，貼上步驟五的網址。
4. 輸入發布密碼（步驟三訂的），按「確認，發到BAND」。
5. 看到「已發到 BAND」，按鈕變成「✅ 今日已發布」，就完成了。到 BAND 看看那篇文。

想先單獨測試發布程式：在 Apps Script 編輯器選 `testPost` 按「執行」，會真的在 BAND 發一篇測試文，測完記得到 BAND 刪掉。

## 平常怎麼用

- 每天早上：教師登記 → 早自習頁 → 「📣 發到BAND」→ 看一下預覽（可以直接改字）→ 輸入密碼 → 確認。
- 「這台裝置記住密碼」：自己的電腦或手機可以勾，下次不用再打；**教室共用電腦不要勾**。
- 同一天發過了，按鈕會顯示「✅ 今日已發布」。真的要再發一次（例如內容改了），要勾「確定要再發一次」。

## 常見問題

- **顯示「發布密碼不對」**：確認跟指令碼屬性的 `PUBLISH_PASSWORD` 一模一樣（大小寫、空白）。
- **顯示「連不上發布程式」**：確認網址是 `…/exec` 結尾，而且部署時「誰可以存取」選了「所有人」。
- **顯示「BAND 沒有發成功」**：通常是 access token 過期或 band_key 填錯。重新拿 token、執行 `listMyBands` 確認 band_key。到 Apps Script 左邊「執行項目」可以看到 BAND 回覆的錯誤。
- **改了 Apps Script 程式碼**：要按「部署」→「管理部署作業」→ 編輯（鉛筆）→ 版本選「新版本」→ 部署。網址不會變。
- **想換發布密碼**：直接改指令碼屬性的 `PUBLISH_PASSWORD`。之前勾過「記住密碼」的裝置，下次發布時重新輸入新密碼即可。
- **金鑰可能外流了**：到 BAND 開發者網站撤銷／重新產生 access token，再更新 `BAND_ACCESS_TOKEN`。
